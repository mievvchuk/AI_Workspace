Від предмета до відповіді за три кроки

  1. Додайте предмет

    Назва й опис. Значок підбирається сам з понад 40 навчальних категорій, і його можна змінити.

  2. Завантажте матеріали

    Лекції, методички й код. Після індексації вони стають контекстом для кожного запитання з цього предмета.

  3. Питайте й перевіряйте

    Чат з посиланнями на джерела, розбір лабораторної та діагностика знань з підсумковим звітом.

    chunks = await load(sid)
    if not chunks: return []
    top = rank(chunks, q)[:3]
    # крок іде в журнал
    log.step("search", len(top))
    return top
